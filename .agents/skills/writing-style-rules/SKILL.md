# 文体のルール

## 主語・述語
- 無生物主語は、その場で作った組み合わせを避け、誰が何をしたかを名指しで書く
  - 「データが示している」「課題が浮き彫りになる」「文脈に落ちてくる」は使わない
  - 「腑に落ちる」「薬が効く」のように辞書に用例がある組み合わせは使ってよい
- 「一般に」「多くの人は」「現代では」を避け、その一般論を述べているのが誰か（自分・あなた等）を書く

## 言葉の強度
- 形容詞には比較対象を、動詞には目的語を同じ文に書く
  - 「強い」「効く」「深い」「速い」を単独で置かない。「深く効く」のように重ねるだけでは対象が無いままなので避ける
  - 「効く」を、対象を省いたまま「うまくいく」の代わりに使わない
- 明確な理由が無い強い形容を使わない。理由が曖昧なら、曖昧だと明記した上で形容する
- 「非常に」「かなり」「普通に」「〜すぎる」を1段落に2つ以上入れない
- 「いい質問ですね」等、フィラーやクッションのみを目的とした言葉から始めない

## 構成
- 手順（何をするか）と理由（なぜそうするか）は分けて書く。手順を先にまとめ、理由は後ろにまとめる。手順の文中に理由・条件・実装詳細を挟み込まない
- ある条件を示せば否定・補集合が自動的に導ける場合、補集合を重ねて書かない。例:「Xなら進めてよい」と書けば「Xでなければ保留する」は自明で、重ねて書く必要はない
- 同じ主題語が短い範囲で繰り返し登場する場合、主題を一度立てて以降は省略する
- 実装手段の詳細が別の場所（設定ファイル自体のコメント等）に既に記録されている場合、ここではその実装がもたらす規則（結果）だけを書き、手段を重ねて説明しない
- 既に述べた内容を言葉を変えて繰り返しているだけの節・文は削る。強調・対比のために意図的に繰り返す場合は例外とする
- 補足が長い、または主節から独立した論点を持つ場合は、括弧・読点に押し込めず別の文に分ける
- 節・文の一部だけをピンポイントで修正した場合も、確定前に修正箇所を含む文全体を読み直す
- 見出しは名詞句にする。命題型の見出しにしない
- 「AではなくBだ」「単なるAではなくB」は「Bだ」と書く
- 3項目の並列表現が必須か常に疑う。2つか1つに削れないか先に考える
- 箇条書きは並列できる事実の列挙だけに使う。理由と判断は地の文で書く
- 語尾と着地をばらす「シンプル。それだけ。」のような断片化をしない。体言止めを避ける
- 末尾に内容を繰り返すだけのまとめ段落を置かない。不要な免責を付けない

## 語彙
- 以下の語は、文脈上使う必然性がない場合は禁止する: 手触り、解像度、泥臭さ、熱量、本質、思想、装置、営み、文脈、設計、真理、虚飾、禁欲的、美学、境地
- 英語から日本語への翻訳調を避ける: 指している、示している、物語っている、収斂する
- 記述対象分野で一般に使われていない、他分野または直訳のカタカナ語を避ける
  - 例:「思考のOSをアップデート」は「考え方を変える」に直す
