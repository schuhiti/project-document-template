# ADR-0007: todo.mdの棚卸し境界をADR-0003の(1)(2)に限定する

## Context
ADR-0005は「セッション境界（Handoff更新のタイミング、ADR-0003）」でtodo.mdを棚卸しすると定めたが、ADR-0003の更新条件は(1)中断・終了直前 (2)コンテキスト圧縮の前後 (3)再開に支障が出る大きな決定、の3つを含む。このうち(3)は内容トリガーであり時間的な区切りを意味しない。この区別をdocumentation-rules側で個別に定義していたが、これはADR-0005の文言と食い違っており、skillがADRの実質的な意味を書き換える形になっていた。

## Decision
todo.mdの棚卸しは、ADR-0003の(1)(2)（時間的な区切り）でのみ行う。(3)（大きな決定の発生）はHandoffの更新は伴うが、todo.mdの棚卸しは伴わない。セッションが継続している間、todo.mdの項目が失われる心配はないため。

## Consequences
todo.mdと「セッション」の定義の整合が取れる。(3)のみでHandoffを更新した場合、todo.mdは棚卸しされないまま残る（意図通り）。ADR-0005本体は変更しないため、両者を合わせて読む必要がある。

## Alternatives Considered
ADR-0005をsupersedeして全文を書き直す案は、変更点が棚卸し境界の限定のみであるのに対して過剰なため却下した。
