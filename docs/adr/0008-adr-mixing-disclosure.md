# ADR-0008: テンプレート内のフレームワーク由来ADRと、配布先プロジェクトのADRの混在は、README.mdで開示する

## Context
テンプレート化に伴い、`docs/adr/`にはこの文書体系自体の設計判断（本ADRを含むADR-0001〜0008）が同梱される。これらは配布先の新規プロジェクトにとっては「自分のプロジェクトの出来事」ではなく「採用したフレームワークの決定」であり、Contextの記述（「本検討中」等）がそのまま読むと事実と異なる。番号空間の衝突（テンプレート更新と配布先の新規ADRが同じ番号を取り合う可能性）も検討した。

## Decision
番号空間を分けたり（例: F接頭辞）、別ディレクトリに分離したりはせず、`docs/adr/README.md`（テンプレートのみに同梱）でフレームワーク由来（0001〜0008）とプロジェクト自身（0009〜）の区別を開示する。`index.md`は機械的な一覧のみに留め、説明はREADME側に書き分ける。README.mdのfrontmatterの扱いはdocumentation-rulesを参照。

## Consequences
既存の「1ディレクトリ・1index」の型を変えずに済む。root（このプロジェクト自身）にはこの区別が存在しないため、README.mdはテンプレート側にのみ同梱し、rootには作らない。

## Alternatives Considered
フレームワーク由来のADRにのみ接頭辞を付ける案（例: F0001）は、ファイル名・見出し・全ての相互参照を書き換える必要があり過剰なため却下した。別ディレクトリへの分離案は、indexの仕組みが二重化するため却下した。番号空間の衝突への個別対策は、テンプレートに配布後の更新マージの仕組みが存在せず実際には起きないと判断し、見送った。
