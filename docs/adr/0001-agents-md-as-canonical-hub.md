# ADR-0001: AGENTS.md をプロジェクト前提・ルール参照の正本とする

## Context
AIエージェントは特定のツールに固定しない方針である。一方、ツールごとに固有のコンテキストファイル（例: CLAUDE.md）が存在し、どれを正本とするか決めないと、同じ内容を複数箇所に維持する二重管理が発生する。

## Decision
クロスツール標準であるAGENTS.mdを正本とする。特定のツールがAGENTS.mdを直接読まない場合は、そのツール専用ファイルからAGENTS.mdを薄く参照・インポートする形にする。

## Consequences
ツールを追加・変更しても文書の二重管理が発生しない。一方、AGENTS.md未対応のツールでは「常時参照される」ことを担保する個別設定が別途必要になる（未確認。採用ツール決定後に対応）。

## Alternatives Considered
特定ツール（例: Claude CodeのCLAUDE.md）を正本にする案は、ツールを固定しないという前提と矛盾するため却下した。
