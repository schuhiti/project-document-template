# Stopをセッション境界リマインダーに使うのをやめた

`session-boundary-reminder.sh`をStop/PreCompact両方で使っていたが、Stopでの運用を廃止しPreCompact専用にした。

理由: Stopは「セッションが終わる直前」ではなく「アシスタントの1ターンが終わるたび」に発火する。ADR-0003が求める境界（セッション終了直前・コンテキスト圧縮直前）のうち、Stopが近似できるのは前者だけだが、その近似は粒度が粗すぎる。実際の運用では、作業ツリーが汚れている（コミット前）間は毎ターン同一のリマインダーが繰り返し出続け、会話上のノイズになった。

「セッション終了直前」はそもそも自動検知に向かない。ユーザーがセッションを終了し次のセッションを開始するという運用が主なパターンであり、区切りを付けるのはユーザー側の操作であってAI側から観測できる事象ではない。したがってこの境界はhookではなくhabit（ADR-0003の基準を都度思い出す）で対応する。

一方PreCompactは実際に稀な・意味のある境界であり、毎ターン発火という問題が無いため、リマインダーとして機能する。

対比: `docs/knowledge/pretooluse-hook-limits.md`はPreToolUseがブロック以外の手段を持たないための廃止、本件はStopが境界の代理として粒度が粗すぎるための縮小。廃止理由の系統が異なる。
