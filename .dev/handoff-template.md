# Handoff テンプレート

新しい引き継ぎを書く際は、この構成に沿って `.dev/handoff.md` を**丸ごと上書き**する（差分ではなく全置換）。目安は数十行。内容が肥大化してきたら、確定した部分を定住先（premise/ADR/knowledge/skill/Issue）へ移してから書き直す。

未検証の前提: 常に単一の作業スレッドがアクティブであることを想定している。並行して複数のスレッドを扱う場合の構成は未検討。トリガー: 実際に複数スレッドを同時に扱う必要が生じた時に設計する。

セクションが空の場合の扱い: 「人間からの申し送り事項」「次にやること」は毎回確認する窓口なので、空でも「（現在なし）」と書いて残す。「関連」は純粋なポインタなので、指す先（Issue/PR等）が実在しない場合はセクションごと省く。
