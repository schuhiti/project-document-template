# 検討: scratchにおける時系列記録の例外

ADR-0004の「結論だけを残し、一部始終は書かない」という基準は、記録する時点で結論がまだ存在しない場面では機能しない。次のいずれかに該当する間は、例外として時系列の記録を残してよいのではないか、という仮説:

- 非決定的・環境依存の不具合の原因究明中（再現条件自体が試行の列挙からしか見えない）
- 複数案を横並びで比較する必要があり、個々の結論だけでは比較できない
- セキュリティインシデント対応中

該当する実例はまだない。

トリガー: 上記いずれかの実例が1件出た時点でADR化を検討し、`documentation-rules`へ反映する。
