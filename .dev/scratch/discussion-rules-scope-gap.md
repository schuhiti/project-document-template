# 検討: discussion-rulesの適用範囲の偏り

discussion-rules（`.agents/skills/discussion-rules/SKILL.md`）は、実際には「未決定・保留・作業仮説の扱い」に内容が偏っている。証拠の重み付け、合意形成の進め方、議論の構造化など、一般的な検討・議論の進め方に関する知見は扱っていない。

原因: このSkillは`document-types.md`のskill行の基準（scratchで繰り返し確立されたものだけを昇格）に従って育てたが、本検討自体が文書体系という「保留・作業仮説の調整が大量に発生する対象」を扱ってきたため、実際に繰り返し遭遇した教訓が偏った。

対応: descriptionは実態（未決定・保留の扱い）に合わせて狭めた。一般的な議論運営の知見は、今は書き足さない。先回りして書くのは、実際に繰り返し遭遇していない内容を書くことになり、ADR-0004のゲートの精神に反する。

トリガー: 保留・作業仮説と無関係な、一般的な議論運営の知見（証拠の重み付け、合意形成等）が実際に繰り返し必要になった場面に遭遇した時。その時、discussion-rulesへ追加するか、descriptionを再び広げるかを検討する。
